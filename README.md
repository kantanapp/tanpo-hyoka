# 担保評価メモ｜社内検討用プロトタイプ

株式会社gen ／ 株式会社フェアー様向け

不動産担保の融資可否を、社内決裁の場で会話するための1枚を自動生成するプロトタイプ。
お客様に直接融資額を提示するものではない（社内資料のため貸金業法の表示規制は対象外）。

## 構成

```
index.html   ← これ1枚のみ。外部依存・ビルドなし
README.md
```

CSS・JavaScript は `index.html` 内に内包。CDN・npm パッケージは一切使用していない。

## 公開

GitHub Pages（`main` / root）。
確認用のため `<meta name="robots" content="noindex,nofollow">` を設定済み。
**本番公開時はこの行を外すこと。**

## タブ構成

| タブ | 内容 |
|---|---|
| 入力 | 物件・建物・現地条件・既存債権 |
| 評価メモ | 判定サマリー＋担保余力バー＋内訳＋確認事項＋近隣取引 |
| 基準値 | 単価・耐用年数・解体費・補正率・掛け目・LTV・下限（全て編集可） |
| 考え方 | 設計思想の解説（社内共有用） |
| ヒアリング | フェアー様への確認項目 A〜H（34問）＋依頼資料3点 |

## 計算ロジック

```
土地評価  = 坪単価 × 土地面積
建物評価  = 再調達価格 × 延床 × (耐用年数 - 築年数) / 耐用年数
解体費    = 建物価値ゼロのとき控除
補正      = 角地 / 旗竿 / 道路幅 / 傾斜 / 浸水
─────────────────────────
積算評価額
  × 処分想定掛け目        → 処分想定価格
  × LTV（設定順位別）      → 担保設定可能額
  − 既存残債              → 担保余力
  ± レンジ幅              → 表示レンジ
```

足切り条件（再建築不可・接道2m未満・市街化調整区域・面積下限）に該当した場合、
評価計算を行わず「該当なし」で終了する。

## パラメータ

**すべての数値は仮置き。** `index.html` 冒頭の `const P = {...}` に集約してある。
実データおよびフェアー様の社内基準が判明したらここを差し替える。
画面の「基準値」タブからも一時的に変更可能（リロードで初期値に戻る）。

坪単価の情報源は未確定。候補は路線価・公示地価・不動産取引価格情報・成約価格情報・
レインズ・社内過去取引の6つ。単価は計算式の外に出してあるため、
情報源が後から決まっても作り直しにはならない。

## 変更時の注意

- `index.html` 単体で完結させる。外部ファイルに分割しない
- 数値をロジック内に直書きしない。必ず `P` に定義して参照する
- 判定は「否」と断定せず「該当なし」と表示する（人が覆せる余地を残すため）
- 金額は必ずレンジで表示する（1本の数字で断言しない）
